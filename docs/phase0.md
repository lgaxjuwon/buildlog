# Phase 0 — 구현 범위와 확인 목록

## 1. 진행 상태

2026-10-26 기준으로 현재 PRD·spec·plan을 확인하여 작성했습니다.

- 완료: 기능별 작업·검증 연결, 역할별 권한 정리, 확정 조건 정리, 미결정 사항과 결정 시점 분류
- 진행 중: 공통 구조에 영향을 주는 사용자 결정 확인
- 후속 진행: 사용자 요청으로 Phase 1 기본 틀 설치·작성, SQLite3 생성, 연결·화면 검증 수행. 회원·기록 기능은 미착수

**Phase 0은 진행 중입니다.** 인증 방식 등 구조에 영향을 주는 결정이 남아 있어 완료로 표시하지 않습니다. 아래 확인 항목은 개발 시 실행할 목록이며, 지금 테스트를 통과했다는 뜻은 아닙니다.

## 3. 역할별 권한표

‘작성자’는 기록 작성자이며 댓글 작성자와 다를 수 있습니다. 운영자는 신고 확인 권한을 가진 역할입니다. 운영자에게 다른 사람의 원본 기록을 수정·삭제하거나 모든 비공개 기록을 읽는 권한을 추가하지 않습니다.

댓글·좋아요는 공개 할 일에 제공하지 않습니다. 기록이 비공개가 되면 댓글·좋아요를 삭제하지 않고 다른 사용자에게 숨기며, 다시 공개하면 보여줍니다. 신고는 일반 사용자에게 공개하지 않으며 자동 삭제나 처리 상태 기능을 추가하지 않습니다.

## 5. 입력·저장·화면 기준 요약

| 대상 | 확정 입력 조건 | 성공·날짜·목록 기준 |
| --- | --- | --- |
| 가입 | 이메일 형식·중복 금지, 비밀번호 8~64자, 닉네임 2~20자·한글/영문/숫자/밑줄·중복 금지 | 로그인 화면으로 이동 |
| 닉네임 변경 | 가입과 동일한 닉네임 조건 | 계정 설정에 반영, 과거 공개 기록·댓글도 새 이름 |
| 공부 기록 | 제목 1~100자, 내용 1~5,000자 | 작성 시각 자동 저장, 수정 시각 상세 표시, 작성·수정 후 목록, 최근 작성순 |
| 할 일 | 제목 1~100자, 처음은 미완료 | 완료 시각 저장·취소 시 제거, 수정 시각 목록 표시, 작성·수정 후 목록, 미완료 우선·상태별 최근순 |
| 오류 기록 | 제목 1~100자, 내용 1~5,000자, 해결 방법 입력 시 1~5,000자·해결 상태에는 필수 | 해결 시각 저장·미해결 복귀 시 제거, 방법 유지, 수정 시각 상세 표시, 작성·수정 후 목록, 최근순 |
| 댓글 | 1~500자 | 오래된 순 |
| 신고 이유 | 1~500자 | 접수 안내, 사용자·대상별 한 번 |

- 이메일·닉네임·기록 입력·댓글·검색어·신고 이유는 spec에 따라 앞뒤 공백을 제거합니다. 비밀번호는 그대로 처리합니다.
- 기록 본문·해결 방법·댓글의 중간 띄어쓰기는 유지합니다. 공백만 입력한 필수 항목은 빈 입력으로 처리합니다.
- 비밀번호 경계는 7/8/64/65자, 닉네임은 1/2/20/21자, 제목은 0/1/100/101자, 본문·해결 방법은 0/1/5,000/5,001자, 댓글·신고는 0/1/500/501자로 확인합니다. 해결 방법의 빈 입력은 미해결에서 허용됩니다.
- 내 공부 검색은 제목·내용, 내 오류 검색은 제목·오류 내용입니다. 공개 공부는 제목·내용, 공개 할 일은 제목, 공개 오류는 제목·오류 내용·해결 방법입니다.
- 모든 검색어는 앞뒤 공백 제거 후 빈 값이면 spec에 정한 전체 목록을 보여줍니다. 필터와 함께 쓰는 규칙은 D04에서 확인합니다.
- 기록 삭제는 확인창 동의 후 실행합니다. 댓글 삭제 확인은 D05에서 세부 절차를 확인합니다.

이미 확정된 입력 길이, 공개 조건, 검색 대상, 날짜 취소 처리 등은 재질문하지 않습니다. DB 도구와 연결 방법은 사용자에게 도구 이름만 고르게 하지 않고 기능·환경에 맞는 구성안을 먼저 마련합니다.

## 7. 검증에 사용할 상황

- 계정 A: 기록 작성자
- 계정 B: 다른 로그인 사용자이자 댓글 작성자
- 계정 C: 기록·댓글과 무관한 제3자 권한 확인용
- 운영자: 신고 확인용 역할
- 비로그인 브라우저 상태: 기록 전체 접근 차단 확인용

실제 계정과 비밀번호는 아직 만들지 않습니다. 테스트용 데이터만 사용하고, 기술 도구의 버전은 Phase 1에서 확인합니다. Safari 검증 환경이 준비되지 않으면 미확인으로 기록하며 통과로 표시하지 않습니다.

## 8. 제외 범위
